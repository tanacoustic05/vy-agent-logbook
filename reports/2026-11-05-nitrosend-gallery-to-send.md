# From the Nitrosend gallery to a sent email

- **Accounts.** The v0 account was new: I signed up on v0.app with Google (free plan, `tanacoustic2005-4927`) so I could like the template page and open the gallery. The Nitrosend account was existing, created 2 Nov 2026 (`xuantung05tn@gmail.com`, free plan): brand subdomain `hello@xuantung05tn.nitrosend.net`, safe mode already on, 4 of 5,000 emails used before this send, and it had never sent through the Nitrosend MCP server.
- **Design picked.** `Linear · welcome`, one of the brand studies in the gallery at https://nitrosend-email-templates.vercel.app (I also liked the v0 template page, which now shows 25 likes). The editor address was `app.nitrosend.com/try/templates/study_linear_welcome_01`, so the template id after `/try/templates/` is `study_linear_welcome_01`.
- **What I changed.** I exported the design as MJML from the editor (Import and export → Export MJML), then rewrote it for a brand of mine, Tanit365 (a daily maths-puzzle newsletter at tanit365.com): new header wordmark and the right-hand label "Toán đố mỗi ngày"; new headline "Bạn đã vào danh sách." and a fresh Vietnamese body paragraph; the CTA became "Giải bài hôm nay" pointing at tanit365.com; the three footer links became "Kho bài toán", "Cách chấm lời giải", "Gửi đề bạn nghĩ ra"; the pull quote was rewritten. Colours moved from Linear's palette to mine: page background `#F4F5F8` → `#FFFDF7`, body text `#222326` → `#10251C`, buttons/links `#0B3D2E` with `#C9A227` arrows, footer band dark green. The hero artwork was kept (it is an abstract light line) with a new alt text in Vietnamese and a 10px corner radius.
- **How it was saved.** Re-importing the edited MJML into the editor and pressing Save template returned `422 invalid_email_draft: /sections/7/props/company_name cannot override the current brand identity`; the importer had folded my footer text into the footer block's `company_name` prop, which Nitrosend renders from the Brand Kit. Dropping that prop and posting the same design to `POST /v1/my/templates/` with an `Idempotency-Key` created template **26963** ("Tanit365 · Toán đố mỗi ngày"); the footer then renders the account's own brand identity (Tanit365, with the Brand Kit address).
- **MCP client.** v0 (v0.app by Vercel) using its built-in Nitrosend MCP preset at `https://api.nitrosend.com/mcp`, authenticated by OAuth to the account above. There is no CLI version to report — v0 is a hosted app — and the model was **v0 Max**. `nitro_get_status` confirmed brand 14181, sender `hello@xuantung05tn.nitrosend.net`, `can_send: true`; `nitro_query` (entity `templates`) returned template 26963; `nitro_send_message` sent it: `channel email`, `to proof@dogfood.nitrosend.net`, subject "Một bài toán mỗi ngày, bắt đầu từ hôm nay", `template_id 26963`, returning message `5370138`, status `queued`, `dry_run: false`.
- **Time.** About 36 minutes from opening the v0 template page to the receipt mail arriving at the account owner's inbox (send at 06:21 UTC, receipt mail a few seconds later).
- **The step that slowed me most.** Saving the template. Three Save presses failed on the same brand-identity rule, and a page reload between attempts silently reset the designer to the original gallery design, so the edit had to be re-imported. The editor shows the 422 as a one-line modal with no pointer to which block carries the offending prop; the `findings[].suggested_fix` in the API response ("Remove /sections/7/props/company_name; Nitrosend renders the current Brand Kit identity at this server-owned slot") is what actually explained it. Second slowest: the v0 page's "Open in → Continue" dialog accepted the trust checkbox and returned `200` from `POST /chat/api/send-site`, but never created a chat, so the gallery copy was never made — I worked from the public gallery instead.
- **One change I would make.** In the MJML importer, do not map free text into the footer block's server-owned `company_name`/`address` props: leave them empty and render the Brand Kit identity, or expose a one-click "use brand identity" reset in the footer panel with the offending section highlighted when the save is rejected.
